# Practice Unit Testing Project

This project contains a set of utility functions and their unit tests using Mocha and Chai.

## Installation

```bash
npm install
```

## Running Tests

To run tests with HTML report generation:

```bash
npm run test
```

## Code Coverage Analysis

To analyze code coverage:

```bash
npm run coverage
```

## Linting

To run ESLint:

```bash
npm run lint
```

To automatically fix linting errors:

```bash
npm run lint:fix
```

## Project Structure

- `utils/` - utility functions
- `test/` - unit tests
- `reports/` - HTML test reports
- `coverage/` - code coverage reports

## Requirements

- Node.js
- npm
- Code coverage must be at least 80%
